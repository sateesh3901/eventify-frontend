## ✨ Features

- 🏠 **Home Page** — Events showcase with search & filters
- 🔐 **Auth Pages** — Login & Register with role selection
- 🎪 **Events** — Browse, search, filter, view details
- 🎟️ **Ticketing** — Book free/paid tickets with QR codes
- 💳 **Razorpay** — Secure payment checkout integration
- 💼 **Career Fair** — Browse jobs, apply with resume upload
- 📊 **Dashboards** — User, Host, Admin role-based dashboards
- 📷 **QR Scanner** — Scan & validate tickets at entry
- ⏰ **Countdown Timer** — Live event countdown on detail page
- 📱 **Fully Responsive** — Works on mobile & desktop
